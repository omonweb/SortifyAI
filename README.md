# SortifyAI — AI-Powered Resume Intelligence Platform

## Overview

SortifyAI is a multi-service hiring intelligence platform designed to automate candidate screening, resume evaluation, recruiter workflows, and hiring decision support using AI-powered semantic analysis and backend-driven ranking pipelines.

The platform enables recruiters to create job requirements, upload candidate resumes in bulk, evaluate candidates using semantic matching and skill-gap analysis, and manage hiring workflows through a centralized dashboard.
