daily startup commands :

    1. docker compose up -d

            sortify-postgres
            sortify-redis
            sortify-minio
            


    3. check service: docker exec -it sortify-postgres psql -U postgres

    4.  cd frontend
        npm run dev

    5.  cd ingestion-gateway
        npm install
        npm run dev

cd ai-worker
python worker.py



docker compose down
