Layers and their responsibilities:
``````````````````````````````````
_______________________________________________________________________________________
| Layer      | Responsibility                       | Example                         |
| ---------- | ------------------------------------ | ------------------------------- |
| DTO        | Represent incoming/outgoing API data | `SignupRequest`, `UserResponse` |
| Validation | Ensure request is well-formed        | `@Email`, `@NotBlank`, `@Size`  |
| Service    | Business logic                       | Hash password, assign role      |
| Entity     | Represent persisted data             | `User`                          |
| Repository | Database access                      | `findByEmail()`                 |
